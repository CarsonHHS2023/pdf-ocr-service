# Project Glossary

| Field | Value |
|---|---|
| Document Type | Project Glossary |
| Authority Domain | Atlas repository and project terminology reference |
| Applies To | Defined Atlas product, platform, document, processing, reader, archive, learning, service-property, and canonical-data terms used in repository documentation |

## Atlas

The product name for one Document Intelligence Platform containing Smart Reading OS and Smart Archive as peer applications over a shared Document Intelligence Core.

## Smart Reading OS

An Atlas application for reading faster, understanding deeper, and remembering more effectively. Roadmap v2 includes Speed Reading, Flashcards, Mind Map, and Notes within Smart Reading OS.

## Document Intelligence Platform

The technical category for the shared platform that turns source documents into canonical content, evidence-backed archive knowledge, and learning objects.

## Document

A durable logical record in the system of record representing a source work or item managed by the platform.

## Book

A reader-facing concept for a document-like item, especially where existing reading workflows use book terminology.

## BookProfile

A profile or metadata view that describes a book for reader-facing experiences. TODO — Pending Decision: exact long-term relationship between BookProfile and Document Core concepts.

## SourceFile

The durable original file supplied to the platform, such as an uploaded PDF.

## DocumentVersion

A versioned representation of a document's accepted content or structure.

## Page

A durable page identity associated with a source document or document version.

## Asset

A durable user/application-facing binary or media object.

## Artifact

A temporary processing, debug, or result object.

## Observation

A model output. An observation is not necessarily canonical truth.

## Fact

A durable archive assertion accepted by the system and connected to supporting evidence.

## Evidence

Traceable support for a fact, observation, or canonical content decision, usually linked back to source content.

## ProcessingRun

A durable record of a processing activity, such as ingestion, OCR, extraction, or enrichment.

## OCR Run

A processing run specifically related to OCR execution or OCR result ingestion.

## Reader

The user-facing reading experience or component that presents content to a user.

## Speed Reading

A product pillar focused on reading workflows that help users read faster.

## Focus Mode

A reader experience that reduces distraction and supports concentrated reading.

## Structured Reader

Historical wording for reader-oriented structured presentation work. Under Roadmap v2, this belongs within M4 Smart Reading OS rather than being a standalone current milestone.

## Reader Content Stream

A stable reader-facing content protocol for delivering structured content to the presentation layer.

## Smart Archive

An Atlas peer application focused on organizing documents, preserving evidence, cross-document retrieval, and keeping needed information available.

## Learning Capabilities

Smart Reading OS capabilities such as notes, flashcards, mind maps, quizzes, summaries, and review workflows derived from document knowledge.

## durable-business-stateless

A service property meaning the service may manage temporary execution state, but does not own durable business entities or workflows.

## Canonical Data

The versioned content accepted by the system of record.
